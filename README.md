IT Asset Management System
Overview

The IT Asset Management System is a desktop application built using C#, Windows Forms, and SQL Server. The system was designed to help organizations track and manage technology assets such as laptops, desktops, tablets, printers, and Chromebooks.

The application allows users to add, update, search, and delete device records while maintaining information such as asset tags, serial numbers, device status, assigned users, maintenance history, and model year.

Features
Add new devices to inventory
Update device information
Delete devices from inventory
Search and filter device records
Track device assignments
Track device status
Record maintenance information
View device statistics through a dashboard
Validate user input to prevent incorrect data entry

Development Process

This project was developed to strengthen skills in C# application development and database management. Microsoft Copilot was used as a development assistant to help troubleshoot issues, improve validation logic, refine SQL queries, and provide guidance throughout the software development process. The final application demonstrates practical experience with desktop application development, relational databases, and inventory management systems.
